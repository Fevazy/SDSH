# Contributing

We are currently **not** accepting pull requests, code patches or any other
forms of code modification **UNTIL** our Contributor License Agreement (CLA) is
set up. Once it's ready, we'll updaate this file with instructions.

If you discover a **serious or critical** issue (security hole, huge memory
leak, etc.) and have a way to fix, you may email `fevazy@yandex.ru` with
subject `[SDSH] CRITICAL REPORT`. In this case, we'll ask you to sign a CLA
before we can merge your changes.

**NOTE:** GitHub Issues are still welcome. If you have any ideas, find bugs or
see some "bad code" (all we make mistakes), feel free to open an Issue. We
monitor them regularly and address them as soon as possible.
